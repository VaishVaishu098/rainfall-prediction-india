# Rainfall Prediction in India

An interactive Streamlit dashboard for analyzing historical rainfall patterns across India and predicting annual rainfall.

## Project Overview

This project analyzes rainfall data from 1901–2015 to identify historical, seasonal, monthly, and regional rainfall patterns and provides a rainfall prediction for the upcoming year.

## Features

- Historical rainfall trend analysis
- Seasonal and monthly rainfall analysis
- Regional rainfall analysis
- Annual rainfall prediction
- Interactive data explorer
- Visualization of rainfall patterns

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Scikit-learn
- Streamlit

## Dataset

The project uses historical rainfall data for India covering 1901–2015 along with district-wise rainfall information.
